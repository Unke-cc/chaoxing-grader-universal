# 超星作业智能批改技能输出风险与质控档案 (Output Risk Profile)

本档案定义 `chaoxing-grader-universal` 在多操作系统（Windows / Linux / macOS）实际用于高校教学评卷过程中的主要质量风险及对应的防控工程机制。

---

## 一、高风险场景与防控机制

| 风险项 | 潜在危害 | 防控策略与代码实现 |
| :--- | :--- | :--- |
| **及格线拦截导致无法提交** | 超星默认及格线通常为 60 分，低于 60 分会被强制弹窗拦截打回重做，导致批改流水线中断 | **60.0 分硬性底线保护**：任何已交作业的学生总分最低不低于 60.0 分，从源头杜绝拦截弹窗 |
| **平行班级或历史作业串改** | 教师端常同时打开多个班级或多门作业的标签页，误判 URL 导致批错对象 | **强标识符过滤**：严格基于目标班级 ID（`clazzid`）和作业 ID（`workId`）进行双重比对过滤 |
| **特定学生分数超标** | 教师针对特定学生（如免修、特殊考核）提出明确的分值上限（如不超过 89 分） | **学生名单微调截断**：打分阶段自动对名单内特定学生的主观题小分做精准压制，确保总分严格不超标 |
| **题目顺序乱序导致错判** | 超星作业对学生端题目顺序随机打乱，硬编码题号会导致判题错位 | **基于题干特征动态路由**：提取题干关键词并与知识库/标准答案匹配，实现题序解耦 |
| **实验题文档误判** | 实验题通常含有代码工程包或实验报告附件，大模型按纯文本判卷会导致误判 | **文档附件安全跳过**：检测到云盘挂载（`attach-iframe`）或附件下载链接时，提取文件元数据并按量规打分 |
| **网络波动导致加载超时** | 异步刷新页面因网络延迟导致 DOM 节点未挂载完全，抽取到空试卷 | **就绪检测与重试机制**：轮询验证 `document.readyState` 及输入框节点数量，超时自动重试 |
| **多平台桌面切屏与焦点丢失** | 操作系统的桌面窗口管理器被抢夺焦点，导致教师在打字或前台操作中断 | **CDP 底层直连**：绕过系统 GUI 窗口管理器，通过本地端口协议与渲染管线通信，实现真正的后台静默 |

## 二、评语体系合规性控制

1. **三档覆盖，语气鼓励肯定**：
   - 杜绝消极、嘲讽或带有贬低性质的评语。
   - 三档评语全部采用建设性、正向激励的表达方式：
     - 优秀档：`作答规范，思路清晰，值得表扬`
     - 良好档：`基础扎实，作答良好，继续保持`
     - 改进档：`作业完成规范，有部分需要改正，继续加油`
2. **禁止虚构采分点**：
   - 严格依据学生作答与标准答案的吻合度打分，扣分点有据可查。
